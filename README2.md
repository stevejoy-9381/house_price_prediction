Predict house prices based on property features using a regression model with real-world data.

## 📌 Problem Statement

Estimating house prices is a critical task in the real estate industry. Prices depend on multiple factors such as location, size, number of rooms, and amenities.

This project aims to build a machine learning model that can accurately predict house prices based on these features.

---

## 💡 Solution Overview

This project uses **Linear Regression**, a supervised learning algorithm, to model the relationship between house features and prices.

- Predicts house prices based on user input  
- Uses structured dataset (real estate data)  
- Provides real-time predictions via web interface

## 📊 Dataset

- Source: Kaggle (Bangalore House Price Dataset)  
- Features include:
  - Location  
  - Square Footage  
  - Number of Bedrooms (BHK)  
  - Bathrooms  
  - Price (target variable)

## 🤖 Model Details

- Model: Linear Regression  
- Task: Regression (predict continuous values)  
- Accuracy: **86%**  
- Preprocessing:
  - Handling missing values  
  - Removing outliers  
  - Feature engineering  
- Evaluation Metrics:
  - R² Score  
  - Mean Squared Error (MSE)
